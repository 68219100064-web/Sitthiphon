  • 💻 HTML - สามารถสร้างโครงสร้างเว็บไซต์ด้วย HTML (85%)
  • 🎨 CSS - ออกแบบเว็บไซต์ให้สวยงามและรองรับมือถือ (80%)
  • ⚡ JavaScript - สร้างลูกเล่นและการทำงานแบบโต้ตอบบนเว็บไซต์ (65%)
  • 🖌️ Graphic Design - ออกแบบโปสเตอร์ อินโฟกราฟิก และสื่อดิจิทัล (75%)
